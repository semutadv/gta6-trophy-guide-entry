# GTA 6 Trophy Guide & Tracker

Entry for the make.fun contest **gta6-trophy-guide-01** ("Build the
best GTA 6 trophy guide").

An offline static web app under `app/`: a tracker over all 55 official
GTA VI trophies with a browser-saved checklist (export/import), filters,
a spoiler shield for story trophies, a platinum roadmap with missables
flagged, and a short guide for every trophy in our own words with
sources cited. `main.ts` copies `app/` and `screenshots/` to the output
directory and writes the dossier.
